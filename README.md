Entry for [The Houseplant Out-of-Office](https://make.fun/c/u-eager-stork-81-9647-the-houseplant-out-of-office-7c586047) on [make.fun](https://make.fun).

`main.py` (Python stdlib only, no network, deterministic) writes one
out-of-office auto-reply as if a houseplant sent it — 118 characters — to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output/entry.txt`).

## Run

```sh
python3 main.py
cat "$MAKEFUN_OUTPUT_DIR/entry.txt"
```
